# Hamzawy Radio — راديو حمزاوي

تطبيق راديو للإذاعات المصرية لأندرويد TV (وبيشتغل كمان على الموبايل والتابلت)، بيكمل تشغيل في الخلفية حتى لو رجعت للشاشة الرئيسية.

## المميزات
- محطات مصرية مقسّمة (أخبار، أغاني، قرآن) وكل محطة ليها أكتر من رابط بث، ولو واحد وقع بيجرّب التاني لوحده ويعيد الاتصال.
- تشغيل في الخلفية بخدمة وسائط (MediaSession)، وبيشتغل مع أزرار الريموت (تشغيل/إيقاف/التالي/السابق).
- أيقونة **المظهر** (أو زر القائمة في الريموت): ثيمات جاهزة + إضافة ثيم من صورتك، ولون التمييز (الإطار حوالين العنصر المحدد) بيتغيّر حسب الصورة.
- ربط الموبايل: افتح عنوان بيظهر على التلفزيون من متصفح الموبايل وابعت صورة ثيم أو أضف محطة برابط البث.

## إزاي تجيب ملف APK
**أسهل طريقة (من غير ما تنزّل أي برنامج): GitHub Actions**
1. اعمل حساب على github.com وأنشئ مستودع (Repository) جديد.
2. ارفع كل ملفات المجلد ده على المستودع (Add file ← Upload files). لازم يترفع مجلد `.github` كمان (لو مش ظاهر عندك: في ماك اضغط Cmd+Shift+. ، وبديل ليه: من GitHub اختار Add file ← Create new file واكتب الاسم `.github/workflows/build-apk.yml` والصق محتوى الملف).
3. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**.
4. بعد دقايق افتح العملية اللي خلصت ونزّل `HamzawyRadio-debug-apk` من **Artifacts**، وفك الضغط هتلاقي `app-debug.apk`.

**أو من Android Studio:** افتح المجلد، استنى الـ Sync، وبعدين Build ← Build APK(s).

## التركيب على التلفزيون
انقل `app-debug.apk` للتلفزيون بفلاشة، أو بتطبيق Downloader، أو بـ `adb install app-debug.apk`، وفعّل «التثبيت من مصادر غير معروفة» لو طلبها.

## الاستخدام
- **المظهر:** اختار الزرار من أعلى الشاشة (أو اضغط زر القائمة). اختار ثيم جاهز، أو «إضافة ثيم» ← «من الجهاز أو فلاشة USB» أو «من الموبايل (واي فاي)».
- الصورة بتتقص 16:9 وبتتصغّر وبتتحفظ جوه التطبيق، فتفضل شغالة حتى لو شلت الفلاشة. تقدر تتحكم في تغميق الخلفية، وتحذف ثيمك بضغطة مطولة عليه.
- **إضافة محطة:** زرار «ربط الموبايل» ← افتح العنوان من الموبايل ← اكتب الاسم ورابط البث. اضغط مطولًا على محطة أضفتها علشان تحذفها.

## ملاحظات
- روابط البث متجمعة من أدلة عامة ومحدّثة بالبحث وقت كتابة المشروع، ولم أقدر أجرّبها من بيئة التطوير. لو محطة مش شغالة، غيّر الرابط في `app/src/main/assets/stations.json` أو أضف رابط جديد من «ربط الموبايل».
- لو التلفزيون مفيهوش تطبيق ملفات، استخدم «من الموبايل».
